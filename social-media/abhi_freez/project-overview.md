---

## Workflow (4-Step Content Pipeline)

```
1. Topic Researcher     → Finds the "villain" or "hook" (2-4 word topic)
2. Background Image     → Generates cinematic background visual (no text)
3. Content Strategist   → Creates headline + 3-point content in JSON format
4. HTML Generator       → Combines image + content into final Instagram-ready HTML
```

## Topic Rotation Strategy

Rotate across engagement types each week:
- **Mon/Tue:** Saves content (tools, skills, how-to)
- **Wed/Thu:** Shares content (myth-busting, hot takes)
- **Fri/Sun:** Comments content (polls, predictions, controversy)

Avoid repeating villains or themes — track in History Log.
